# Keyline

Keyline is an open-source Android keyboard (IME) with custom layouts, themes and background images, one-handed and floating modes, clipboard history, emoji, built-in translation and smart suggestions.

## Features

- Multiple languages (Persian, English, Arabic, German, Spanish, French, Russian, Turkish) with editable layouts
- Themes, glass-style keys and custom background images
- Gboard-style toolbar that gives way to word suggestions while typing
- One-handed and floating modes with drag-to-resize handles
- Adjustable vibration strength, key height and key opacity
- Clipboard history, emoji panel, text editing pad and translator

## Building

Open the project in Android Studio, or run:

```
gradle assembleRelease
```
